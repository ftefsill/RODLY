# Последняя буква

Игра в слова для 2–4 человек на одном устройстве: каждый следующий игрок называет
слово, начинающееся на последнюю букву предыдущего слова. Если слово заканчивается
на Ъ, Ь или Ы — берётся буква перед ней. Слова не должны повторяться. У каждого
игрока 3 жизни; жизнь теряется за просроченный или пропущенный ход. Побеждает
последний оставшийся игрок.

## Особенности

- Полностью статический сайт: чистый HTML/CSS/JS, без фреймворков, сборщиков и
  внешних запросов во время игры — работает офлайн и без проблем с доступом в РФ.
- Встроенный словарь (~58 000 лемм: существительные, глаголы, прилагательные и др.,
  источник — [Badestrand/russian-dictionary](https://github.com/Badestrand/russian-dictionary),
  CC BY-SA 4.0) для мягкой проверки слов: если слова нет в словаре, игроки сами решают,
  принять его или нет.
- Таймер на ход (можно выключить), жизни, подсветка цепочки слов, адаптивная вёрстка,
  поддержка тёмной темы.

## Файлы

- `index.html` — разметка
- `styles.css` — стили
- `script.js` — логика игры
- `words.js` — словарь для проверки слов

## Как выложить на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `word-chain-game`).
2. Загрузите в него все файлы из этой папки (`index.html`, `styles.css`, `script.js`,
   `words.js`), сохранив их в корне репозитория.
   - Через веб-интерфейс: "Add file → Upload files" → перетащите файлы → Commit.
   - Или через git:
     ```bash
     git init
     git add .
     git commit -m "Первая версия игры"
     git branch -M main
     git remote add origin https://github.com/<ваш-логин>/word-chain-game.git
     git push -u origin main
     ```
3. В репозитории откройте **Settings → Pages**.
4. В разделе "Build and deployment" выберите **Source: Deploy from a branch**,
   ветку **main** и папку **/(root)**. Нажмите **Save**.
5. Через 1–2 минуты сайт появится по адресу:
   `https://<ваш-логин>.github.io/word-chain-game/`

Больше ничего настраивать не нужно — сайт не делает никаких запросов к серверу.

## Локальная проверка перед публикацией

Просто откройте `index.html` в браузере — всё заработает без веб-сервера.
